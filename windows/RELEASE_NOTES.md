Prima versione Windows di TinyHand (port nativo C#/.NET 8 + WPF + Win32 dell'app macOS di Kamran Ahmed, MIT).

**Installazione:** scarica `TinyHand-win-x64.zip`, estrailo e avvia `TinyHand.exe` (Windows 10/11 x64, nessuna installazione di .NET richiesta). SmartScreen può segnalare l'app non firmata: *Ulteriori informazioni → Esegui comunque*.

**Uso:** clic sull'icona nell'area di notifica o **Ctrl+Alt+H** per accendere/spegnere, clic = tap, trascina = disegna (Ctrl per la freccia), **Ctrl+Alt+X** cancella, **Esc** esce, **Alt**+clic = clic reale, doppio **Shift** = click-through. Automazione con `start tinyhand://toggle`.

Dettagli, corrispondenza dei tasti e limitazioni note nel README incluso nello zip.
